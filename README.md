# Rate Tracker

A simple vanilla HTML dashboard for monitoring the current usage/export rate window and viewing the daily schedule. Toggle between GloBird ZeroHero and Powershop EV Day (AusNet, effective 1 October 2026); the selection is remembered in the browser.

## Structure

- [index.html](index.html) contains the page markup.
- [styles/globird-tracker.css](styles/globird-tracker.css) contains the styling.
- [scripts/globird-tracker.js](scripts/globird-tracker.js) contains the interactive JavaScript logic.

## Run locally

Open [index.html](index.html) in a browser to view the tracker.

## Linting

Install dependencies and run:

```bash
npm install
npm run lint
```
