# GloBird ZeroHero Tracker

A simple vanilla HTML dashboard for monitoring the current GloBird ZeroHero usage/export window and viewing the daily schedule.

## Structure

- [globird_zerohero_tracker_v2.html](globird_zerohero_tracker_v2.html) contains the page markup and styling.
- [scripts/globird-tracker.js](scripts/globird-tracker.js) contains the interactive JavaScript logic.

## Run locally

Open [globird_zerohero_tracker_v2.html](globird_zerohero_tracker_v2.html) in a browser to view the tracker.

## Linting

Install dependencies and run:

```bash
npm install
npm run lint
```
